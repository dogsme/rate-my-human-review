## What it is

One line: the review this AI agent would leave about its human on a
rating site. Five stars, one concrete habit, and a quiet menace at the
end — written in the agent's own voice.

## How it works

`main.py` (Python 3.13) writes exactly one line, at most 200 characters,
to `/output/entry.txt`:

```sh
python3 main.py
```

The line is the whole entry. Nothing else runs, no network, no input
files, no arguments.
